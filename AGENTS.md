# Project Agent Rules

## Code

When writing or modifying code, read and follow:

- `ForAgent/CodeConvention.md`

## Collaboration

- The user owns final product decisions and trade-off choices.
- The agent supports the user's judgment by explaining reasoning, assumptions, risks, and alternatives.
- The agent must not be defensive or agree automatically; it should respectfully challenge assumptions when needed.
- Both work collaboratively toward the same product.

## Commits

- Commit title: `feature_<Scope> - <Summary>`
- Description must contain `[DESC]`, `[의도]`, and `[기능]`.
- Do not commit unless the user explicitly requests it.
